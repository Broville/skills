# Security Best Practices Reference Guide

This directory contains language and framework-specific security reference documents. File naming convention: `<language>-<framework>-<stack>-security.md`

For example:
- `python-django-web-backend-security.md` — Django web backend security
- `python-general-web-backend-security.md` — Python-agnostic web backend security
- `javascript-express-web-backend-security.md` — Express.js backend security
- `javascript-general-web-frontend-security.md` — JS-agnostic web frontend security
- `go-gin-web-backend-security.md` — Gin framework backend security
- `go-general-web-backend-security.md` — Go-agnostic web backend security

## Creating Reference Documents

Each reference document should contain:

1. **Framework overview** — What the framework does and its security model
2. **Secure defaults checklist** — Security settings that should be enabled by default
3. **Common vulnerabilities** — Known patterns specific to the language/framework
4. **Code examples** — Secure vs insecure patterns
5. **Configuration snippets** — Secure configuration templates
6. **Testing guidance** — How to verify security settings are applied
