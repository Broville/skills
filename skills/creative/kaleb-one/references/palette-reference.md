# Kaleb One — Complete Palette Reference

Full color token tables for all four palettes. For the Obsidian token table, see the main SKILL.md.

## Midnight Ocean

| Token | Hex | Usage |
|-------|-----|-------|
| `--md-sys-color-primary` | `#A1C2F2` | Primary actions, FABs, active states |
| `--md-sys-color-on-primary` | `#1B2D44` | Text/icons on primary |
| `--md-sys-color-primary-container` | `#2A4264` | Container variant of primary |
| `--md-sys-color-on-primary-container` | `#C4DDFF` | Text/icons on primary container |
| `--md-sys-color-secondary` | `#BECAD9` | Secondary actions |
| `--md-sys-color-on-secondary` | `#2A3340` | Text/icons on secondary |
| `--md-sys-color-secondary-container` | `#404958` | Secondary containers |
| `--md-sys-color-on-secondary-container` | `#DAE5F0` | Text/icons on secondary container |
| `--md-sys-color-tertiary` | `#53D8D6` | Teal accent — great for data viz |
| `--md-sys-color-on-tertiary` | `#003736` | Text/icons on tertiary |
| `--md-sys-color-tertiary-container` | `#004F4E` | Tertiary containers |
| `--md-sys-color-on-tertiary-container` | `#7CF5F2` | Text/icons on tertiary container |
| `--md-sys-color-error` | `#FFB4AB` | Error states |
| `--md-sys-color-on-error` | `#690005` | Text/icons on error |
| `--md-sys-color-surface` | `#10151E` | Page background |
| `--md-sys-color-on-surface` | `#DDE5EE` | Primary text |
| `--md-sys-color-surface-container-low` | `#171E28` | Cards at rest |
| `--md-sys-color-surface-container` | `#1C232E` | Dialogs, sheets |
| `--md-sys-color-surface-container-high` | `#262D38` | Hover states |
| `--md-sys-color-surface-container-highest` | `#303844` | Filled cards |
| `--md-sys-color-outline` | `#8C95A4` | Borders, dividers |
| `--md-sys-color-outline-variant` | `#424B58` | Subtle borders |

**Best for:** Dashboards, analytics, data visualization — the teal tertiary really pops in charts.

## Frost (light theme)

| Token | Hex | Usage |
|-------|-----|-------|
| `--md-sys-color-primary` | `#0064C2` | Primary actions (blue) |
| `--md-sys-color-on-primary` | `#FFFFFF` | Text/icons on primary |
| `--md-sys-color-primary-container` | `#D3E3FF` | Container variant |
| `--md-sys-color-surface` | `#F8F8FF` | Page background (light!) |
| `--md-sys-color-on-surface` | `#1B1B1F` | Primary text (dark on light) |
| `--md-sys-color-surface-container` | `#EDEDF5` | Cards, containers |
| `--md-sys-color-outline` | `#767780` | Borders, dividers |
| `--md-sys-color-outline-variant` | `#C6C6CF` | Subtle borders |

**Best for:** Documentation sites, public-facing pages, professional/light UIs.

**⚠️** Frost is a light theme — surface and on-surface roles are inverted compared to the 3 dark palettes.
